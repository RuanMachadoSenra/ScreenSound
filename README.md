# ScreenSound
Projeto desenvolvido durante o curso da Alura

## 📂 Estrutura do Projeto

- `ScreenSound.sln` — solução do Visual Studio contendo os projetos do aplicativo.  
- Pasta `ScreenSound` — código-fonte do aplicativo.  
- `.gitignore`, `.gitattributes` — arquivos de configuração do Git.  
- Outros arquivos auxiliares que fazem parte da configuração padrão (dependências, recursos, etc.).

- ## 🛠️ Funcionalidades
Nesta etapa do projeto já estão presentes:

- Interface gráfica básica (UI) para carregar e exibir lista de músicas.  
- Capacidade de tocar som (arquivo de áudio).  
- Navegação entre faixas (próxima, anterior).  
- Controle de pausa / reprodução.  
- Exibição de metadados básicos da música (nome, artista) — se disponíveis no arquivo.  

## 🚀 Como rodar / usar
1. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/ScreenSound03.git
   cd ScreenSound03
2.Abra a solução ScreenSound.sln no Visual Studio (ou IDE compatível com C#).
3.Restaure os pacotes NuGet, se houverem dependências externas.
4.Compile e execute o projeto.

## Tecnologias usadas
C# / .NET — linguagem principal do projeto.
Biblioteca(s) de áudio (internas ou externas) — para reprodução de som.
Componentes de interface gráfica (Windows Forms, WPF ou equivalente).
